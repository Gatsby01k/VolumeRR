# Движение, интерактивность и состояния

## 1. Главная сцена
OPEN -> Market Lens. Начальный контент уже читаем в серверном HTML. Короткое раскрытие 520-800 ms добавляет глубину к существующему разрезу. Курсор смещает свет максимум на 3 px; текст и controls не двигаются. Нет прелоадера, который блокирует доступ к содержанию.

Выбор региона меняет список и подпись за 220-360 ms. Фокус сохраняется на выбранном элементе. Переход на страну сохраняет выбранный продукт и открывает самостоятельный URL. Изображение не является кнопкой: управление остаётся обычным HTML.

## 2. Motion contract
| Событие | Длительность | Поведение |
| --- | --- | --- |
| Hover / focus | 160 ms | Линия, цвет или стрелка, без прыжка layout |
| Select / toggle | 220 ms | Обновление выбранного состояния |
| Panel / menu | 220-360 ms | Короткое появление, без отсечения hit area |
| Content chapter | 360-520 ms | Один сдержанный вход в viewport |
| Hero reveal | До 800 ms | Одно раскрытие; не повторяется при каждом scroll |
| Route transition | До 360 ms | Старый контекст сменяется новым, URL и focus корректны |
| Validation | Сразу | Текст ошибки и summary без декоративной задержки |
| Submission | Сразу после действия | Disabled submit + pending label, сохранение введённого |

Все значения - проектные параметры. Фактическая плавность проверяется на устройствах. Нет обещания 60 FPS по статичному макету.

## 3. Ограничения
Нативная прокрутка. Нет scroll hijacking, scroll-jacking библиотеки, липкого курсора, бесконечного свечения, hover-only функций или автозапуска тяжёлого видео. Один эффект не закрывает другой. Закрепление допускается только на desktop для короткого учебного flow-блока; длина не более 1.5 экранов, с явным выходом.

Reduced motion отключает pinning, parallax, появление из-за маски и мягкую смену маршрута. Состояния меняются сразу. Никакие тексты не остаются с opacity 0. Настройка Motion доступна в футере и учитывает системную настройку.

Без WebGL остаются CSS-разрез, исходный материал и тот же HTML. При потере контекста canvas удаляется из слоя, интерфейс не перезагружается. Canvas не принимает pointer events и скрыт от screen reader.

## 4. Навигация
Menu trigger - button с aria-expanded и aria-controls. Открытие доступно click, Enter и Space. Escape закрывает меню и возвращает focus. Переход закрывает меню. Desktop dropdown не отрезает появляющиеся пункты анимированным clip-path. Подменю не исчезает, пока пользователь переводит в него указатель.

Mobile navigation - модальный drawer: focus trap, inert фон, закрытие кнопкой/Escape, восстановление scroll и focus. Заголовки и все основные ссылки есть в DOM. Нет второй скрытой копии формы.

## 5. Market Lens и сравнение
Региональные фильтры - toggle buttons, а не tabs, если меняется набор результатов. Подпись с количеством обновляется через polite live region. Поиск имеет label и clear. Очистка не сбрасывает остальные фильтры без отдельной команды.

Country link и Add to brief - разные интерактивные элементы. Нельзя делать всю строку ссылкой и помещать внутри checkbox. Строка сравнения содержит checkbox с полным именем страны. Максимум три страны; четвёртый выбор показывает объяснение и не выбрасывает предыдущие данные.

URL хранит только белый список region, flow, methodType и codes. Неизвестное значение игнорируется с понятным сбросом, не вызывает пустой экран. Параметры сравнения нормализуются в устойчивый порядок.

Состояния: initial; filtered; selected; no_results; no_verified_availability; loading; recoverable_error; stale_data; unsupported_combination. Для неизвестной доступности показывается Scope to confirm, не Disabled без объяснения.

## 6. Brief Rail
Появляется после первого выбранного рынка или продукта. Содержит краткое резюме, количество рынков, Review brief и Collapse. Минимальная высота 56 px, безопасная зона iOS учитывается; страница получает соответствующий нижний padding.

Сохраняются только market IDs, flow IDs и необязательное предпочтение валюты расчёта. По умолчанию sessionStorage. Персональные данные и свободный текст там не сохраняются. Локальное сохранение на более долгий срок - отдельное явное действие пользователя.

Удаление выбранного рынка объявляется screen reader. Переход к форме сохраняет выбор. Back из формы возвращает к исходной странице с теми же фильтрами. Завершение отправки очищает персональные данные в памяти; контекст можно оставить только по явному действию.

## 7. Форма
Четыре шага: Markets -> Products -> Business -> Review.
Первое посещение допускает Not sure yet. Неизвестный рынок не блокирует обращение: Other market + короткое название.

Каждый шаг валидирует свои поля; кнопка Back ничего не очищает. Итоговый Review редактируется по секциям. Неправильное поле получает aria-invalid и aria-describedby; общий error summary содержит ссылки на поля. Фокус при ошибке переходит на summary, а не случайно на первый элемент страницы.

Sending не означает Received. При успехе сервера показывается подтверждение с receiptId. При timeout результат uncertain: пользователь видит Retry safely; повтор использует тот же idempotency key. Дубликат возвращает ту же квитанцию. Ошибка доставки уведомления команде не превращает сохранённое обращение в потерянное.

Состояния: blank; prefilled; partially_complete; field_error; step_error; review; submitting; accepted; uncertain; retrying; rate_limited; recoverable_server_error; unsupported_file; session_expired.
Файлы, платёжные реквизиты и удостоверения не принимаются этой формой.

## 8. Mobile adaptation
До 600 px один столбец и горизонтальная версия разреза. Заголовок переносится по словам; отдельное MARKETS помещается целиком. Таблица сравнения становится группами по критериям. Ключевые действия не скрываются в hover. Поля имеют минимум 16 px, touch targets 44 px, primary action 48 px. Ошибки не меняют высоту соседних секций неожиданно.

Нижняя панель не перекрывает focused field. При открытой клавиатуре панель краткого брифа сворачивается; submit остаётся внутри потока документа, не поверх полей.
