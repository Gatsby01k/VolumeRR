# Визуальная система

## Композиция
Графитовая редакционная поверхность, бумажный слой и один точный разрез. На странице максимум один hero aperture. Его металлическая кромка занимает до 8 px; лаймовый просвет до 2 px. Контент, таблицы и поля остаются плоскими. Красный - короткий терминал фирменной складки и семантическая ошибка в отдельном контрастном тоне.

На 1440 px: внешние поля 64 px, 12 колонок, gutter 24 px, ширина контента 1312 px. Ограничение контейнера 1440 px считается по контентной области; при широких экранах центрирование. Tablet 8 колонок / 32 px, mobile 4 / 24 px / gutter 16 px. Переходы 600, 960, 1280, 1600 px. Шапка 88 / 72 px. Секции desktop 96-128 px вертикально, mobile 56-72 px.

Герой Home на desktop занимает 720-860 px включая шапку. Слева вступление и CTA, справа Market Lens в бумажном раскрытии. На mobile разрез горизонтальный. На 320 px для MARKETS используется отдельный fit-токен, минимально 28 px; всё слово видно. Остальные display-строки 40-52 px. Resize до 200% не обрезает контент.

## Типографика
Unbounded 700 для display, 600 для крупных заголовков. Manrope 400/600/700 для UI и текста. Desktop display 96-124 px, h1 64-88 px, h2 44-64 px; mobile h1 36-44 px, h2 28-36 px. Display leading 1.04, tracking -0.035em. Body 18/28.8 px desktop и 16/25.6 px mobile. Input минимум 16 px. Article measure максимум 68ch.

Файлы variable TTF, WOFF2 и fixed weights включены с OFL. В вебе preload только используемого критического subset/family, font-display swap, metric-adjusted fallback. Не загружать все TTF в браузер. Логотип - отдельный брендовый файл, не текст Unbounded.

## Цвет и контраст
Graphite #090C0D; Paper #F1F0E9; Ink #101719; Platinum #CBD0D2; Lime #CDFF00; Red #FF251E. Лайм используется с тёмным текстом. Светлая подпись на лайме недопустима. Error on dark #FF7A73, error on light #A31C17. Подписи mutedDark #AAB3B6 / mutedLight #586366.

Разделители могут быть декоративными. Границы интерактивных полей используют отдельные inputBorder токены с контрастом не менее 3:1. Focus: 2 px + offset 4 px, лайм на тёмном и #345100 на бумаге. Требуемые роли проверяются qa/contrast.json. Контраст нужен также hover/focus/disabled, иконкам состояния и ошибкам.

## Контролы и размеры
Primary button 48 px высотой, horizontal padding 24 px, маленький 10 px срез на правом нижнем углу. Hit area остаётся прямоугольной и не обрезается. Secondary - текст, стрелка и подчёркивание. Target минимум 44 px. Поле 48-56 px, label сверху, helper/error снизу. Checkbox 20 px внутри 44 px label target.

CountryRow desktop минимум 88 px, mobile 112-136 px. Country link, compare и Add отдельные controls. Сравнение desktop - настоящая таблица с подписанными заголовками; mobile - группы по критериям и странам. Никаких важных подсказок только на hover.

## Логотип и иконки
Используется поставленный wordmark без перерисовки. Clear space минимум высоты буквы V / 2, header optical width 184-208 px. На mobile 144-164 px. Для настоящего SVG нужен исходник владельца; существующий webp пригоден для размера header. Замена файла в том же asset slot не меняет layout.

Иконки stroke 1.5 px, canvas 24 px, оптическое выравнивание. Стрелки единообразны. На 16 px используется упрощённый набор. Объект Manta - самостоятельный companion, не новая версия логотипа.

## Доказательства и данные
Никакого условного logo wall, счётчика объёмов или красивой лицензии. При отсутствии EvidenceRecord используется OperatingSplit и конкретные setup questions. Статус scope, дата review и источник не смешиваются с декоративными надписями.

## Социальная связность
Та же типографика, складка, тонкая лаймовая кромка и единственный красный терминал связывают сайт, посты, avatar и LinkedIn. Manta пригоден для редакционных иллюстраций и коротких переходов; основной wordmark остаётся главным идентификатором.
