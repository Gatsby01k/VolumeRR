# Asset provenance

Primary wordmark and Manta use the previously selected raster originals; approved originals remain byte-for-byte copies in 00-originals. Exports apply canvas trimming, downscaling and format encoding only.

The light-surface wordmark color adaptation and transparent VR extraction were prepared with the built-in image tool using these instructions:

## Light-surface wordmark
Preserve the VolumeRail letter contours, spacing, baseline and distinctive R. Keep the acid-lime V and red R terminal. Change the silver body of the remaining letters and R upper part to graphite #101719 for use on white. Remove background residue and output genuine transparent alpha. No new typography or other objects.

## VR extraction
Extract only the central VR monogram from the approved avatar. Remove the dark background and all decorative diagonal rails. Preserve the frontal lime V, satin-silver R, opening and red diagonal terminal. Output genuine transparent alpha with no plaque, floor or shadow.

These raster adaptations are supplied alongside the untouched originals. They are not an editable vector master or a 3D model.

## Manta motion atlas v2

`manta-poses-v2.webp` is a new six-pose, 3-by-2 transparent atlas generated with the built-in ImageGen tool using the approved original Manta and the supplied `08-manta-storyboard.png` as references. It is a pre-rendered character asset, not an existing asset from the original handoff and not a GLB. The source PNG is retained in `design/manta/pose-atlas-source.png`; the exact prompts and cleanup request are in `docs/manta-asset-prompt.md`. The web export applies only proportional downscaling to 960×640 and WebP encoding. The original posters and wordmark remain available unchanged.
